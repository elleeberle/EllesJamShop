# Elle's Jam Shop

A beautiful, static HTML website for Elle's Jam Shop - a homemade jam business.

## Features

- **Responsive Design**: Mobile-friendly layout that works on all devices
- **Multiple Pages**: Home, About, Products, and Contact pages
- **Modern Styling**: Clean, professional CSS styling with a warm color scheme
- **Easy to Customize**: Simple HTML and CSS structure for quick modifications

## File Structure

```
EllesJamShop/
├── index.html          # Home/landing page
├── about.html          # About page
├── products.html       # Products listing page
├── contact.html        # Contact page
├── styles.css          # Main stylesheet
├── images/             # Image directory for product photos
└── README.md           # This file
```

## Pages Included

### Home (index.html)
- Welcome message
- Featured products section
- Call-to-action button

### About (about.html)
- Company story
- Commitment to quality
- Why choose Elle's Jam Shop

### Products (products.html)
- Full product catalog
- Product cards with descriptions
- Pricing information
- Add to cart buttons

### Contact (contact.html)
- Contact information
- Operating hours
- Contact form
- Business address

## Getting Started

1. Clone or download this repository
2. Add your product images to the `images/` folder
3. Customize the content in each HTML file
4. Update contact information in `contact.html`
5. Open `index.html` in your browser to view the site

## Customization Tips

- **Colors**: The main color (saddle brown #8b4513) can be changed in `styles.css`
- **Content**: Edit text directly in HTML files
- **Images**: Replace placeholder image paths in `<img>` tags
- **Logo**: Modify the `.logo` text in the navigation
